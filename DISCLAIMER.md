# Disclaimer

This project is an independent portfolio piece created for skills 
demonstration purposes only.

It is not affiliated with, commissioned by, endorsed by, or representative 
of Rotherham Metropolitan Borough Council, its employees, systems, 
contractors, or operational data.

All data in this project -- including repair jobs, property references, 
contractor performance figures, tenant satisfaction scores, and KPI results 
-- is entirely synthetic and randomly generated using Python's Faker library. 
It bears no relationship to any real operational data held by Rotherham 
Council or any other organisation.

Contractor names (Mears, Equans) are referenced because they are publicly 
named in Rotherham's Housing Strategy 2025-30, a document available in the 
public domain. Their inclusion does not imply any actual performance data, 
commercial relationship, or endorsement.

KPI targets referenced in this project are drawn from publicly available 
council performance documentation and are used solely to provide a realistic 
benchmarking context for the synthetic data.
